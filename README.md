## 📖 Description
**Nice Name Tags** lets you rename mobs to change parts of how they look and behave.

Just rename a Name Tag in an Anvil using one of the supported texts and use it on the entity you want to change. To make things easier, there’s also a Custom Options button in the Pause Menu that shows all available texts and lets you copy them straight to your clipboard.

## 📋 Features
<details>
<summary>Mute Entity</summary>
Silences an Entity so that it cannot make a sound.
<br><br>
Accepted Texts: "Silent", "silent", "Mute", "mute"
</details>
<details>
<summary>Unmute Entity</summary>
Unsilences an Entity so that it can make a sound.
<br><br>
Accepted Texts: "Unsilent", "unsilent", "Unmute", "unmute"
</details>
<details>
<summary>Change to/Keep Baby</summary>
Changing and locking the age of the Entity as a baby.
<br><br>
Accepted Texts: "Baby", "baby", "AgeLock", "Age Lock", "agelock", "age lock"
</details>
<details>
<summary>Can grow up</summary>
Removes the age lock from an Entity allowing it to grow up again.
<br><br>
Accepted Texts: "Remove Baby", "RemoveBaby", "remove baby", "removebaby"
</details>
<details>
<summary>No Collision</summary>
The affected Entity no longer collides with other Entities.
<br><br>
Accepted Texts: "No Collision", "NoCollision", "no collision", "nocollision"
</details>
<details>
<summary>Collision</summary>
The affected Entity can collide with other Entities again.
<br><br>
Accepted Texts: "Collision", "collision"
</details>
<details>
<summary>On Fire</summary>
Set the affected Entity on fire (only visually).
<br><br>
Accepted Texts: "On Fire", "on fire", "OnFire", "onfire"
</details>
<details>
<summary>No Fire</summary>
Removes the visual fire from the affected entity.
<br><br>
Accepted Texts: "No Fire", "no fire", "NoFire", "nofire"
</details>
<details>
<summary>Stop Zombification</summary>
The affected entity can no longer zombify. Zoglins, Piglins & Piglin Brutes only.
<br><br>
Accepted Texts: "No Zombie", "no zombie", "NoZombie", "nozombie"
</details>
<details>
<summary>Start Zombification</summary>
The affected entity can zombify again. Zoglins, Piglins & Piglin Brutes only.
<br><br>
Accepted Texts: "Zombie", "zombie"
</details>
<details>
<summary>Villager Type</summary>
Changes the current type of a Villager.
<br><br>
Accepted Texts: "Desert", "desert", "Jungle", "jungle", "Plains", "plains", "Savanna", "savanna", "Snow", "snow", "Swamp", "swamp", "Taiga", "taiga"
</details>
<details>
<summary>Clear Name</summary>
Removes the Custom Name from an Entity.
<br><br>
Accepted Texts: "ClearName", "Clear Name", "clearname", "clear name", "RemoveName", "Remove Name", "removename", "remove name"
</details>
<details>
<summary>Clear Modifications</summary>
Removes all Name Tag modifications from the affected Entity.
<br><br>
Accepted Texts: "ClearAll", "Clear All", "clearall", "clear all", "RemoveAll", "Remove All", "removeall", "remove all"
</details>
